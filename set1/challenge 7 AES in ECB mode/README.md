# Set 1, Challenge 7: AES in ECB Mode

Decrypt the bundled Base64-encoded ciphertext using AES-128 in ECB mode and
the key `YELLOW SUBMARINE`.

## Requirements

Install the project dependency from the repository root:

```bash
pip install -r requirements.txt
```

## Input

Place the Cryptopals challenge input in `7.txt` beside `solution.py`.

## How to Run

From this folder, run:

```bash
python solution.py
```
